# build-switcher

**Русский** | [English](README.en.md)

Мод для [TERA Toolbox](https://github.com/tera-private-toolbox/tera-toolbox) (patch 100.02, Asura): одна кнопка переключает билд **танк ⇄ ДД**:

| Что | Как переключается |
|---|---|
| Символы (glyphs, «Набор 1–5») | Мод сохраняет список включённых символов и применяет его пакетом `C_CREST_APPLY_LIST`. Если сервер применил не всё, мод доводит символы по одному через `C_CREST_APPLY`. |
| Таланты (страница 1–5) | `C_LOAD_EP_PAGE`. Мод запоминает этот пакет, когда вы сами переключаете страницу в окне талантов. |
| Экипировка (оружие, броня, бижутерия, пояс, брошь) | Мод запоминает надетые предметы и надевает их одним пакетом `C_CHANGE_EQUIP_PRESET`, как набор экипировки в клиенте. Если нужного предмета нет в сумке (лежит в банке), мод так и напишет. |
| Костюмы (голова, лицо, облик оружия, костюм, спина, следы) | Отдельная часть билда, тем же пакетом. Можно переключать вместе с экипировкой или отдельно. |
| Помощник (питомец или партнёр) | Мод запоминает вызванного помощника и вызывает его пакетом `C_REQUEST_SPAWN_SERVANT`, если его нет рядом. Помощник последнего включённого билда вызывается и при входе в игру. |
| Улучшение умений (опции 1/2/3) | `C_RQ_SKILL_POLISHING_CHANGE_OPTION`. Мод запоминает этот пакет, когда вы сами выбираете опцию. |

Структуры пакетов для талантов и улучшения умений не описаны в tera-data. Поэтому мод **учится**: сохраняет пакет, который отправляет клиент, и потом отправляет такой же. Integrity-хэш для пакетов с padding toolbox пересчитывает сам.

## Установка

**Вариант 1. Один файл (рекомендуется).**

1. Создайте папку `TeraToolbox/mods/build-switcher/`.
2. Положите в неё только [`module.json`](https://raw.githubusercontent.com/omk-education/build-switcher/main/module.json) (правый клик по ссылке → «Сохранить как»).
3. Запустите Toolbox. Он увидит новый мод и сам скачает остальные файлы.

**Вариант 2. Вручную.** Скачайте репозиторий (Code → Download ZIP) и скопируйте его содержимое в `TeraToolbox/mods/build-switcher/`.

Ваши билды и выученные пакеты хранятся в `config.json` в папке мода. Обновления этот файл не трогают.

## Обновление

Мод обновляется стандартным механизмом Toolbox: при каждом запуске Toolbox сверяет файлы с `manifest.json` в этом репозитории и скачивает изменившиеся.

- Автообновление включается и выключается переключателем у мода на вкладке «Мои модули» (Installed mods).
- Если вы ставили мод вручную до версии 3.1, замените один раз `module.json` на новый: в старом не было адреса сервера обновлений.
- Текущая версия показана внизу настроек в окне мода (⚙).

### Для разработчиков

`manifest.json` содержит SHA-256 каждого файла мода. GitHub Actions пересобирает его при каждом пуше в `main`. Вручную:

```
node tools/manifest.js          # пересобрать manifest.json
node tools/manifest.js --check  # проверить, что он актуален
```

Новые файлы мода попадают в манифест автоматически. Исключены служебные (`.github`, `tools`, `.git*`) и пользовательский `config.json`. При изменениях поднимайте `version` в `module.json`.

## Первая настройка (один раз)

1. Зайдите на персонажа.
2. Вручную включите **танк-сетап**: символы, страницу талантов и опции улучшения умений для танка (например, «Сила гиганта (защита)» → «Всплеск силы»).
   Важно: **переключайте их кликом прямо сейчас**, а не оставляйте как были. Так мод увидит пакеты и запомнит их.
3. Напишите в чат: `/8 build save tank`
4. Так же вручную включите **ДД-сетап** (символы, страница талантов, «Мощный удар IX» → «Удар в уязвимое место» и т.д.).
5. `/8 build save dd`
6. Проверьте: `/8 build show tank` и `/8 build show dd`. Если мод пишет «ещё не знает пакеты», один раз переключите в игре то, что он перечислил.

## Использование

| Команда | Действие |
|---|---|
| `/8 tank` или `/8 build tank` | переключиться в танк |
| `/8 dd` или `/8 build dd` | переключиться в ДД |
| `/8 build save <имя>` | сохранить текущее состояние как билд (можно своё имя, например `pvp`) |
| `/8 build <имя>` | применить билд |
| `/8 build list` | список билдов персонажа |
| `/8 build show <имя>` | состав билда и что совпадает с текущим состоянием |
| `/8 build status` | текущее состояние и выученные пакеты |
| `/8 build del <имя>` | удалить билд |
| `/8 build bar` | показать или скрыть панель кнопок |
| `/8 build lock` | закрепить или открепить панель кнопок |
| `/8 build gui` | открыть окно управления |
| `/8 build lang ru` / `en` | язык интерфейса и сообщений |
| `/8 build part <имя> <часть> on/off` | включить или отключить часть билда: `equip`, `costume`, `servant`, `talents`, `crests`, `polish` |
| `/8 build debug` | вкл/выкл лог пакетов (в чат и в лог Toolbox) |
| `/8 build forget` | забыть выученные пакеты |
| `/8 build on` / `off` | включить / выключить мод |

## Что переключать (части билда)

У каждого билда шесть частей: **Экипировка**, **Костюмы**, **Помощник**, **Таланты**, **Символы** (изученные умения) и **Улучшения** (улучшение умений). Любую можно отключить, тогда мод её не трогает:
- в окне: редактор билда (✎) → «Что переключать», или просто нажмите на плашку на карточке билда (зачёркнутая — отключена);
- в чате: `/8 build part tank equip off` (части: `equip`, `costume`, `servant`, `talents`, `crests`, `polish`; `on` или `off`).

Пример: экипировку и символы вы меняете сами, а мод переключает только таланты и улучшения.

«Перезаписать текущим» сохраняет все части заново, а выбор включённых частей, иконка, горячая клавиша и показ на панели остаются прежними.

## Помощник

Перед сохранением билда вызовите нужного помощника (питомца или партнёра): мод запомнит его вместе с билдом. При переключении на билд мод вызовет этого помощника, если его ещё нет рядом.

При входе в игру мод вызывает помощника последнего включённого билда (⚙ → «Переключение» → «Вызывать помощника при входе в игру»). Если помощника уже вызвал другой мод (например, auto-pet), повторно мод его не вызывает. Чтобы моды не вызывали помощника по очереди, оставьте вызов при входе включённым только в одном из них.

## Окна мода

Окна работают только в **TeraToolbox.exe** (с интерфейсом), в CLI их нет.

**Панель кнопок** — маленькое окно поверх игры только с кнопками билдов. Появляется при входе в игру, скрыть и вернуть можно командой `/8 build bar`.
- Нажатие на кнопку включает билд. Включённый билд подсвечен золотым. Подсказка на кнопке показывает горячую клавишу.
- На панели показываются билды с включённым «Показывать на панели кнопок» (переключатель в редакторе билда). Скрытые билды помечены в окне управления плашкой «не на панели».
- «Скрывать, когда игра неактивна»: панель исчезает, если вы переключились в другое окно или свернули игру, и появляется снова, когда вы вернётесь. Пока активно окно управления, панель видна.
- По умолчанию панель не забирает фокус у игры: после нажатия можно сразу продолжать играть.
- Перетаскивание: зажмите кнопку мыши на панели (можно прямо на кнопке билда) и ведите. Сдвиг меньше 5 пикселей считается обычным нажатием. Позиция запоминается.
- Чтобы панель случайно не сдвинуть, её можно закрепить: замок на панели, ⚙ → «Закрепить панель» или `/8 build lock`. Закреплённая панель не двигается, а кнопки работают как обычно.
- Над иконками при наведении появляются 🔒 (закрепить или открепить), ⚙ (окно управления) и × (скрыть панель).
- Панель сама подстраивается под число и размер кнопок.
- В настройках можно убрать фон кнопок или выбрать его цвет (палитра или свой) и непрозрачность, убрать рамку и подписи, сделать панель прозрачной (над игрой видны только кнопки), выбрать размер и расположение (в строку или в столбец), прозрачность «в покое».

**Окно управления** — билды, редактор и настройки. Открывается кнопкой ⚙ на панели или командой `/8 build gui`.
- Блок «Сейчас» показывает, какой билд включён, и предупреждает, если вы в бою, открыто окно взаимодействия или не удалось занять горячую клавишу.
- Большая иконка в карточке включает билд. Отметки ✓ и ✗ показывают, что совпадает с текущим состоянием, плашки включают и отключают части билда.
- Кнопка ✎ открывает редактор билда: имя, что переключать, иконка (больше 40 штук в четырёх группах и свои SVG), цвет, горячая клавиша, порядок в списке, «Перезаписать текущим» и «Удалить».
- Кнопки заголовка: ⚙ настройки, ▭▭▭ показать или скрыть панель кнопок, 📌 поверх всех окон, свернуть, закрыть.

**Свои иконки (SVG).** Редактор билда (✎) → вкладка «Свои» → «+» или перетащите .svg файлы в редактор.
- Размер файла до 150 КБ, загрузить можно до 60 иконок. Они хранятся в `config.json` и не пропадают при обновлениях.
- Одноцветные иконки сразу красятся в цвет билда. Многоцветные сохраняют свои цвета, а галочкой «Цвет билда» их можно залить одним цветом.
- Из файла удаляется всё, что может выполнить код или что-то загрузить: скрипты, обработчики событий, внешние ссылки, встроенные картинки, анимации.
- Много бесплатных игровых иконок есть на [game-icons.net](https://game-icons.net) (лицензия CC BY 3.0).

**Горячие клавиши.** Работают глобально, даже когда окна свёрнуты или закрыты (пока запущен Toolbox). Сочетание перехватывается у всех программ, включая игру, поэтому выбирайте свободное: например, `Ctrl+Alt+1` или `F9`. Одиночные буквы без Ctrl, Alt или Shift назначить нельзя.

## Настройки (⚙ в окне)

| Раздел | Что можно настроить |
|---|---|
| Панель кнопок | показывать при входе, поверх всех окон, не забирать фокус у игры, скрывать, когда игра неактивна, закрепить панель, размер кнопок, фон кнопок (вкл/выкл, цвет, непрозрачность), рамка кнопок, подписи, прозрачная панель, в строку или в столбец, непрозрачность и прозрачность «в покое» |
| Окно управления | открывать при входе, поверх всех окон, масштаб, тема (TERA, Графит, Багровая, Изумруд, Светлая), язык |
| Переключение | вызов помощника при входе в игру, запрет в бою, поведение при открытом окне взаимодействия, пауза между пакетами, горячие клавиши |
| Уведомления | сколько показывать результат, дублирование в чат, подтверждение удаления и перезаписи |
| Данные | забыть выученные пакеты, сбросить положение и прозрачность окон |

## Открытые окна взаимодействия

Пока открыто окно NPC, банка, торговли, крафта и подобное, сервер отклоняет смену всего набора символов. Ручной клик по «Набору» в игре в это время тоже не сработает: мод напишет об этом в чат.

Что мод делает в этом случае, задаётся в настройках («Если открыто окно взаимодействия»):
- **По одному** (по умолчанию): ставит символы по одному. Сервер это разрешает, но выходит медленнее.
- **Не трогать символы**: переключает только таланты и улучшения.
- **Отменить переключение**: ничего не делает и просит закрыть окно.

## Символы и «Наборы» 1–5

Номер «Набора» хранит только клиент игры. Сервер получает лишь список символов, поэтому новый список записывается в «Набор», выбранный сейчас. Держите выбранным свободный «Набор» (например, 5): мод будет менять только его. Если хотите переключать символы сами, отключите часть «Символы» в редакторе билда («Что переключать»).

Мод меняет только то, что отличается. Если символы уже стоят, их он не трогает.

## Язык интерфейса

Окно и сообщения мода доступны на русском (основной язык) и английском. Переключение: ⚙ → «Окно управления» → «Язык», или командой `/8 build lang en` (`ru` — обратно).

Переводы лежат в `ui/i18n.js`. Ключ перевода — русская строка, поэтому для нового языка достаточно добавить его в `LANGUAGES` и словарь в `DICT`. Команда `node tools/i18n-check.js` проверяет, что переведены все строки (её же запускает GitHub Actions).

## Файл `config.json`

Почти всё настраивается в окне. Вручную в файле стоит менять только `shortcuts`: короткие команды чата (по умолчанию `["tank", "dd"]`). Если вы назвали билды иначе, впишите сюда их имена.

Билды хранятся отдельно для каждого персонажа. Выученные пакеты общие.

## Если что-то не переключается

1. `/8 build debug`
2. Переключите в игре вручную то, что не работает.
3. В лог Toolbox попадут имена и тела пакетов. Пришлите эти строки, по ним можно поправить мод.
