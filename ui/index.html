Символы и «Наборы» 1–5

Номер «Набора» хранит только клиент игры. Сервер получает лишь список символов, поэтому новый список записывается в «Набор», выбранный сейчас. Держите выбранным свободный «Набор» (например, 5): мод будет менять только его.

Если открыто окно взаимодействия (NPC, банк, торговля, крафт), сервер не меняет весь набор сразу. Что делать в этом случае, выбирается выше.
